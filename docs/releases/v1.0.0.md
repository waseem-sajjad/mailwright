# Mailwright 1.0.0

First public release of Mailwright, an open-source drag-and-drop email template builder with an AI email designer, a curated template gallery and inbox-safe HTML export.

![Mailwright editor](https://raw.githubusercontent.com/waseem-sajjad/mailwright/main/docs/screenshots/editor.png)

## Highlights

- **Visual editor.** Rows, columns and 18 block types: heading, text, button, image, divider, spacer, list, menu, social, footer, raw HTML, table, icon grid, product, quote, coupon and callout. Drag-and-drop with undo/redo, keyboard shortcuts, inline text editing with formatting and merge-tag chips, Google Fonts, per-device visibility and a layers panel.
- **AI email designer.** Describe the email and a Gemini-backed designer drafts a complete template, explains its choices and refines it turn by turn. Subject-line ideas, gallery search and email-marketing questions are handled in the same chat. Standard or large (10–14 section) output. Without an API key a built-in rules engine still answers.
- **Template gallery.** 26 ready-made templates, including 20 professional large-format designs across e-commerce, SaaS, hospitality, finance, travel, non-profit, events and education. Open, edit, export.
- **Inbox-safe export.** Table-based HTML with Outlook conditionals, bulletproof buttons, responsive columns and hide-on-device classes; pre-flight checks for missing alt text, placeholder links and unsubscribe links; preview at desktop, tablet and phone widths; JSON import/export.
- **Ready for a public deployment.** One private AI conversation per browser, no vendor or model names exposed, per-IP rate limits on AI routes, a read-only gallery and optional Google AdSense placements.

## Stack

- `apps/web`: React 19, Vite, Tailwind 4, Zustand, dnd-kit
- `apps/server`: NestJS 11, Prisma 7, PostgreSQL, `@google/genai`
- `packages/shared`: the document model, factories, tree operations and the HTML exporter

## Getting started

```bash
git clone https://github.com/waseem-sajjad/mailwright.git
cd mailwright && pnpm install
pnpm db:up                                   # PostgreSQL in Docker
cp apps/server/.env.example apps/server/.env # add GEMINI_API_KEY for the AI designer
pnpm dev                                     # http://localhost:3000
```

See the [README](https://github.com/waseem-sajjad/mailwright#readme) for configuration, deployment and architecture.

## Known limitations

- The AI designer needs a Google Gemini API key; other providers are not wired up yet.
- The gallery is read-only by design; saving your own templates to the server is not part of this release.
- Screenshots and the browser UI were verified in Chrome; other browsers have not been tested systematically.
