# Mailwright 1.1.0

Dark mode, handled both ways inboxes do it.

![Dark preview](https://raw.githubusercontent.com/waseem-sajjad/mailwright/main/docs/screenshots/preview-dark.png)

## Designed dark theme in every export

Clients that honour `prefers-color-scheme` (Apple Mail, iOS Mail, Outlook.com and the new Outlook apps) now get a designed dark rendering instead of an automatic inversion. Exports carry the `color-scheme` and `supported-color-schemes` meta tags, a `:root { color-scheme: light dark }` rule and a dark block that darkens the page, light row bands and content containers, lightens dark text, dividers and links, and leaves brand-coloured bands and buttons untouched. The same rules are repeated under Outlook.com's `data-ogsc` / `data-ogsb` hooks.

## Pre-flight checks for inversion

Gmail and Outlook for iOS/Android ignore all of that and invert colours themselves, so the pre-flight check now simulates it for every heading, paragraph, list, footer and button:

- contrast as designed (WCAG AA: 4.5:1 body text, 3:1 headings and buttons)
- contrast after full inversion (Gmail apps, Outlook mobile)
- contrast after partial inversion, where only light backgrounds are darkened and dark text lightened (Gmail iOS, classic Outlook for Windows)
- a warning for mid-tone text colours, which read poorly in both modes
- an advisory for images on light backgrounds, since transparent logos with dark artwork vanish when inverted

Each warning links to the block so it can be fixed in place.

## Preview in three renderings

The preview dialog has a Light / Dark / Inverted switch next to the device toggle: the designed light and dark themes, and the blunt inversion those other clients apply (with images left alone, as they do). Previews and gallery thumbnails are pinned to a scheme, so they no longer follow the viewer's operating system.

## Fixed

- The Outlook.com dark-mode rules lost the prefix on the second selector of a comma list, which painted the dark page background in every client. Exports from 1.0.0 are unaffected because those rules did not exist yet.

